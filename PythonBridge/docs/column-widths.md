# Webapp column widths

Drag the right edge of a column header to resize it. Open Layout and click **Save layout to profile** to persist the widths for the signed-in user. Header and item layouts are saved separately for Opportunity and Packaging Requests. Each master section also has its own saved widths.

Widths follow column names when columns are reordered or hidden, and restore after reload/sign-in. Reset layout/view restores default widths. Double-click a resize handle to reset that column to 180 pixels. Keyboard users can focus the handle and use Left/Right (10 pixels), Shift+Left/Right (50 pixels), Home (80 pixels), or End (800 pixels).

Resize is available once the saved profile has loaded. Widths are limited to 80?800 pixels. Resizing does not change sorting, data, or Excel output.

Icon/action columns in masters, Customers, the Opportunity overview and Packaging Requests also have a resize handle and a saved width. They default to 180 pixels so multiple icons fit. Narrow action cells wrap their buttons rather than hiding them.

Packaging Request item PIC, assignment, Documents and Response columns can also be resized and saved in the item layout.
